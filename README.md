# WOOH Project — сайт

Промо-сайт Rust-проекта **WOOHRUST**: тёмный gaming / neo-brutalist лендинг, живые данные серверов, график онлайна, правила, страницы политики и условий.

Сайт статический: только HTML, CSS и нативные ES-модули. **Сборки нет**, зависимостей нет — достаточно раздать папку по HTTP.

---

## Быстрый старт

ES-модули не работают через `file://`, поэтому нужен локальный сервер:

```powershell
# Python
python -m http.server 8000 --directory wooh-v2

# или Node.js
npx serve wooh-v2
```

Открой `http://localhost:8000/`.

Без сервера страница тоже откроется, но живые данные и вкладки правил будут неактивны: встроенный fail-safe через 2,5 секунды уберёт занавес и покажет контент.

```
│  │  ├─ legal.css            # стили юридических страниц
│  │  ├─ responsive.css       # медиазапросы (подключать последним)
│  │  └─ sections/            # по одному файлу на секцию
│  ├─ js/
│  │  ├─ main.js              # точка входа лендинга
│  │  ├─ legal.js             # точка входа юридических страниц
│  │  ├─ config.js            # серверы, диапазоны, API, вайп
│  │  ├─ lib/                 # dom, http, format
│  │  └─ modules/             # независимые модули поведения
│  ├─ fonts/                  # 4 WOFF2 (Golos Text + Unbounded, cyr/lat)
│  └─ img/                    # логотип, скриншоты обновлений, карты

```

Порядок CSS в `<head>` важен:

`fonts.css → base.css → components.css → sections/*.css → responsive.css`

## Как это работает

- **Живой онлайн** опрашивается каждые 10 секунд: сначала `/api/servers`, затем публичный монитор, затем кэш в `localStorage` на 10 минут, в конце — демо-данные.
- **График** строится по `/api/online-history`; если API недоступен, рисуется демо-график с пометкой.
- **Правила** — это настоящие HTML-панели. JS только переключает вкладки, поэтому текст читается без JavaScript и индексируется.
- **Анимации**: занавес при загрузке/переходах, reveal при скролле, sticky-стек карточек, горизонтальная галерея серверов на десктопе.
- **Доступность**: клавиатурные вкладки правил, управляемый с клавиатуры график, focus trap и возврат фокуса в мобильном меню, `aria-live` для показаний графика.

## API

Сайт ожидает backend на том же origin:

| Метод | Путь | Назначение |
| --- | --- | --- |
| `GET` | `/api/servers` | Онлайн и очередь по серверам |
| `GET` | `/api/online-history?server=main&range=24h` | Точки графика |
| `POST` | `/api/visit` | Учёт визита, счётчик посетителей |
| `GET` | `/api/site-stats` | Скачивания и посетители |
| `POST` | `/api/launcher-download` | Счётчик скачиваний лаунчера |

Контракты и поведение при сбоях — в [`docs/API.md`](docs/API.md). На статическом хостинге запросы к `/api/*` дают 404 — это ожидаемо, сайт переходит на fallback.

## Ограничения

- ES-модули требуют HTTP(S). Для предпросмотра с диска есть деградация без JS.
- Нет сборщика, транспиляции и полифилов: нужны современные браузеры (Chrome/Edge/Firefox/Safari последних версий).
- Ленивые изображения и часть анимаций могут не срабатывать в фоновой вкладке — это особенность браузера, не сайта.

Скопируй содержимое `wooh-v2/` в корень сайта. Сохрани структуру каталогов и путь `/api/` для backend. Проверь, что сервер отдаёт `.js` как `application/javascript` (иначе модули не загрузятся).
