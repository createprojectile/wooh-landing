# QA

## 1. Локальный запуск

```powershell
python -m http.server 8000 --directory wooh-v2
```

Открыть `http://localhost:8000/`.

Важно:

- Сервер должен отдавать `.js` как `application/javascript`, иначе ES-модули не загрузятся.
- Не проверяй через `file://` — модули заблокируются. Допустима только проверка fail-safe (контент читается, live/вкладки не работают).
- Для юридических страниц: `/privacy/index.html`, `/terms/index.html`.

## 2. Матрица

| Ширина | Что проверять |
| --- | --- |
| 320 px | Нет горизонтального скролла, CTA не обрезаны, длинные заголовки помещаются |
| 390 px | Основной мобильный сценарий: меню, hero, карточки серверов |
| 430 px | Крупный телефон, проверить сетки и отступы |
| 768 px | Планшет: серверы вертикальные, nav скрыт |
| 1024 px | Переход к десктопной сетке |
| 1280 px | Базовый десктоп: sticky-галерея, стек фич |
| 1920 px | Максимальные заголовки, отсутствие пустот |

Быстрая проверка переполнения в консоли:

```js
document.documentElement.scrollWidth === document.documentElement.clientWidth
```

Должно быть `true`.

## 5. Reduced motion

Включи `prefers-reduced-motion: reduce` в DevTools:

- [ ] Занавес не показывается.
- [ ] Reveal-блоки сразу видимы.
- [ ] Анимация числа онлайна отключена.
- [ ] Sticky-стек не масштабируется.
- [ ] Плавный скролл отключён.

## 6. Известные артефакты окружения

Это **не баги сайта**, но они мешают автоматическим проверкам:

1. **Фоновая вкладка.** `IntersectionObserver`, CSS-переходы и `loading="lazy"` могут «замереть». Активируй вкладку или выставь `loading="eager"` перед проверкой картинок.
2. **Headless-скриншоты.** Занавес и reveal могут попасть в кадр в промежуточном состоянии. Дай странице 2–3 секунды или добавь `.no-modules`.
3. **iframe-харнесс для мобильных ширин.** Переходы внутри iframe могут не проигрываться, если вкладка не активна. Фокус и layout проверяются корректно, анимации — в обычной вкладке.
4. **`/api/*` 404.** Ожидаемо на статике; не считается ошибкой.

## 7. Регрессия после правок

Минимум перед сдачей:

1. Открыть главную на 320/390/430/1280.
2. Проверить `scrollWidth === clientWidth`.
3. Переключить все вкладки правил и все диапазоны графика.
4. Проверить копирование и тост.
5. Открыть/закрыть меню на 390 px, проверить фокус.
6. Открыть обе юридические страницы.
7. Просмотреть консоль: только ожидаемые 404 `/api/*`.

## 8. Деплой-чек-лист

- [ ] Загружена вся папка `wooh-v2/` (включая `assets/` и `docs/` — docs можно не публиковать).
- [ ] `.js` отдаётся с корректным MIME.
- [ ] HTTPS включён (нужен для Clipboard API и нормального кэша).
- [ ] `/api/*` проксируется на backend.
- [ ] `robots.txt` и `sitemap.xml` доступны.
- [ ] Canonical и OG-URL указывают на `https://woohproject.ru/`.
- [ ] Проверены 404-страницы хостинга.
- [ ] Кэш статики настроен (хешированных имён нет — используй cache-busting при обновлении CSS/JS).
