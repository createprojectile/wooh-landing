# Дизайн-система

## 1. Принципы

- **Тёмная основа, один акцент.** Почти всё строится на `--bg` и `--fg`; фиолетовый `--accent` используется точечно.
- **Крупная типографика.** Заголовки — Unbounded 900, uppercase, плотный трекинг. Это главный визуальный носитель стиля.
- **Контрастные поверхности.** Карточки чередуются: тёмная, глубоко-синяя, светлая, акцентная.
- **Крупные радиусы.** Панели 28–32 px, карточки 20 px, кнопки — pill.
- **Движение по делу.** Только transform/opacity; всё отключается при `prefers-reduced-motion`.

## 4. Сетка и отступы

| Токен | Значение | Назначение |
| --- | --- | --- |
| `--pad` | `clamp(16px, 3vw, 40px)` | горизонтальные поля секций |
| `--section-y` | `clamp(80px, 12vh, 140px)` | вертикальный ритм секций |
| `--radius` | `32px` | панели, крупные карточки |
| `--ease` | `cubic-bezier(.2,.7,.2,1)` | основные переходы |
| `--spring` | `cubic-bezier(.34,1.56,.64,1)` | кнопки, «пружина» |
| `--curtain` | `cubic-bezier(.76,0,.24,1)` | занавес |

Базовые классы:

- `.section` — `padding: var(--section-y) var(--pad)`.
- `.section-head` — flex-заголовок с описанием, `margin-bottom: clamp(32px,5vh,56px)`.
- `.section-title` — крупный заголовок секции.
- `.panel` — карточка с `--card`, радиус `--radius`, padding `clamp(20px,4vw,56px)`.

Внутренние отступы карточек: 22–28 px на мобиле, 28–56 px на десктопе. Не опускай ниже 20 px — текст начинает липнуть к краям.

## 5. Компоненты

### Кнопки `.btn`
- Высота 44 px, pill, 14 px / 600.
- `.btn--light` — светлая заливка (основное действие).
- `.btn--outline` — обводка (вторичное действие).
- `.btn--lg` — 60 px, 17 px.
- `.btn--sm` — компактная, 44 px.
- Hover: scale/фон; active: `scale(.98)`.
- Не делать кнопку меньше 44 px по высоте — это минимум для тапа.

### Чипы `.chip`
- 40 px, pill, обводка `--line-strong`.
- `.is-active` — светлая заливка.
- Используются для диапазонов графика, серверов и вкладок правил.

### Карточки
- `.feature-card` — sticky-стек, крупный заголовок слева, текст справа.
- `.server-card` — фото на весь экран, градиентный скрим, информация снизу.
- `.update-row` — медиа + текст, чередование сетки.
- `.mini-card` — компактный апдейт.
- `.review` — цитата, три варианта фона (`--dark`, `--deep`, `--light`).
- `.rule` — карточка правила; `.rule--penalty` — акцентная.

### Навигация
- `.nav` — верхняя строка, ссылки скрываются на ≤760 px.
- `.mobile-menu` — полноэкранная панель, крупные ссылки, CTA.
- `.brand` — логотип + WOOH, Unbounded 900.

### Служебные
- `.curtain` — две полосы (тёмная + акцентная), уезжают вверх.
- `.toast` — нижнее уведомление, 1,8 с.
- `.chart` — SVG + сетка + overlay + readout.

## 7. Движение

- Занавес: 560 ms, `--curtain`; акцентная полоса с задержкой 90 ms.
- Reveal: `translateY(28px)` + opacity, 700–900 ms, задержки через `--delay`.
- Sticky-стек: масштаб до 0.94 и brightness до 0.65.
- Кнопки: 250–350 ms.
- Все анимации отключаются в `@media (prefers-reduced-motion: reduce)`.
- Не анимировать `width`, `height`, `top`, `left` — только `transform`, `opacity`, `filter`.

## 8. Адаптивность

| Диапазон | Поведение |
| --- | --- |
| >1000 px | Полная сетка, sticky-галерея, крупные заголовки |
| 761–1000 px | Правая колонка фич уходит влево, сетки сжимаются |
| ≤760 px | Вертикальные серверы, скрытые nav-ссылки, мобильное меню, уменьшенные заголовки |
| ≤420 px | Уменьшенные отступы, одноколоночные соцссылки, компактный бренд |

Проверяй 320, 390, 430, 768, 1024, 1440, 1920 px.

Особые случаи:

- Длинные слова в заголовках фич уменьшены — не возвращай прежний размер.
- Заголовок блока «Скачать» на 1000–1365 px уменьшен до `7vw`: две колонки узкие, и `line-mask` иначе обрезает слово.
- На мобиле префикс `client.connect` скрыт, IP показывается полностью.
- `body { overflow-x: clip }` — страховка, а не решение. Ищи реальный переполняющий элемент.

## 9. Доступность

- Контраст проверяй для текста на `--bg`, `--fg` и `--accent` (на акценте текст тёмный — `--bg`).
- Видимый `:focus-visible`: 2 px `--accent`, отступ 3 px.
- Основные кнопки — 44 px; чипы — 40 px (осознанное исключение).
- Иконки-стрелки декоративные, текст ссылки всегда есть.
- `aria-live="polite"` только у показаний графика; не добавлять его к таймеру.
- Правила: настоящие `role="tab"`/`tabpanel`, roving tabindex.
- Меню: focus trap, Escape, возврат фокуса.
- Изображения: `alt` по смыслу, декоративные — пустой.

## 10. Чего не делать

- Не добавлять светлую тему «на лету»: сайт спроектирован под тёмную.
- Не использовать стандартные синие ссылки — цвет наследуется.
- Не смешивать радиусы 8/12/16 px: система держится на крупных радиусах.
- Не добавлять тени кроме акцентного ring у графика.
- Не вводить новые шрифты: две гарнитуры — осознанное ограничение.
- Не уменьшать межстрочный интервал заголовков ниже `.86` — буквы начнут слипаться.
