# AGENTS.md — WOOH Project site

Инструкция для агентов, которые продолжают работу над сайтом. Читай этот файл первым, затем нужный документ из `docs/`.

## 1. Что это

Статический промо-сайт Rust-проекта **WOOHRUST** (`woohproject.ru`). Без сборки, без npm-зависимостей: HTML + CSS + нативные ES-модули.

- Рабочая папка: `wooh-v2/`
- Пользовательские тексты: **русский**
- Документация: русский (можно смешивать с английскими терминами)
- Внешний вид: тёмный gaming / neo-brutalist, фиолетовый акцент

## 2. Жёсткие правила

1. **Не трогай исходный проект в `../`** (`woohproject.ru/index.html`, `styles.css`, `app.js`, `assets/`, `world/`). Это read-only референс исходной версии.
2. **Не добавляй сборку** (Vite/Webpack/npm) без явной просьбы. Сайт должен оставаться деплоящимся копированием файлов.
3. **Не меняй порядок CSS** в `<head>`: `fonts → base → components → sections/* → responsive`. `responsive.css` обязан быть последним.
4. **Контент правил держи в HTML**, не в JS. `rules.js` только переключает вкладки. Это важно для SEO и работы без JS.
5. **Данные — в `assets/js/config.js`.** Не дублируй ID серверов, IP, диапазоны и расписание вайпа по файлам.
6. **Не удаляй fallback-цепочку** (backend → публичный монитор → кэш → демо). Сайт должен выглядеть живым на статическом хостинге без API.
7. **Проверяй адаптивность** на 320 / 390 / 430 px после правок типографики и карточек.
8. **Не коммить временные файлы** (`_check.html`, скриншоты, логи) — удаляй после проверки.

## 3. Быстрый запуск

```powershell
python -m http.server 8000 --directory wooh-v2
# или
npx serve wooh-v2
```

Открыть `http://localhost:8000/`.

`file://` не подходит: ES-модули блокируются CORS. Встроенный fail-safe через 2,5 с снимает занавес и показывает контент, но live-данные и вкладки не работают.

## 5. Частые задачи

### Изменить сервер / IP / лимит
1. `assets/js/config.js` → `SERVERS` (`monitorId`, `max`, `fallback`).
2. `index.html` → карточка сервера (`data-status`, `data-players`, `data-queue`, `data-copy`).
3. Проверить, что ID совпадает с монитором GameMonitoring.

### Добавить правило
1. Найди нужную панель `#rules-panel-*` в `index.html`.
2. Добавь `<li class="rule"><span>Текст</span></li>`.
3. Для наказания: `<li class="rule rule--penalty"><span>Нарушение</span><span class="rule__penalty">бан N дней</span></li>`.
4. Новые пункты попадают в панель без правок JS; количество проверяй по чек-листу в `docs/QA.md`.

### Добавить обновление
1. Изображение → `assets/img/updates/<name>.png`.
2. В `#updates` добавь `article.update-row` по образцу соседних.
3. Укажи `width`/`height`, `loading="lazy"`, `decoding="async"`.
4. Для мелкого пункта используй `div.mini-card`.

### Изменить цвета/типографику
- Только через токены `:root` в `assets/css/base.css`.
- Не хардкодь hex в секциях, если есть подходящий токен.

### Настроить вайп
- `assets/js/config.js` → `WIPE` (`utcDay`, `utcHour`).
- Текст «каждую пятницу в 16:00 МСК» в hero правится отдельно в `index.html`.

### Подключить реальный API
- Контракты: `docs/API.md`.
- Сайт уже ждёт same-origin `/api/*`; менять код не нужно, если ответы совпадают.

## 6. Инварианты и подводные камни

- **Sticky-галерея серверов** (`320vh` + `translate3d`) управляется из `scroll-effects.js`. На ≤760 px трансформация принудительно сбрасывается, карточки идут вертикально.
- **Reveal** использует `IntersectionObserver`, но в фоновых вкладках/headless может не сработать. Есть страховка через 1,1 с и fail-safe `.no-modules`.
- **Ленивые изображения** в фоновой вкладке не грузятся. Для проверки путей временно ставь `loading="eager"`.
- **Кэш live-данных**: `localStorage['wooh_live']`, TTL 10 минут. При отладке очищай вручную.
- **Демо-график** включается, если API вернул <3 точки. В UI есть пометка — не убирай её.
- **Занавес**: `is-done` запускает уход, `is-hidden` убирает из потока. Inline-fail-safe должен оставаться в `<head>` каждого HTML.
- **Фокус в мобильном меню**: панель `visibility:hidden`; перед `focus()` нужен style flush (`void menu.offsetWidth`). Не убирай его.
- **`overflow-x: clip` на `body`** скрывает случайные переполнения, но не является заменой адаптиву. Проверяй `scrollWidth === clientWidth` у `documentElement`.
- **Длинные заголовки** в карточках фич на мобиле уменьшены до `clamp(30px, 11vw, 52px)` — иначе «ЧЕСТНЫЙ» вылезает за экран. Заголовок «Скачать лаунчер» на 1000–1365 px ограничен `7vw`, иначе `line-mask` обрезает слово.
- **Префикс `client.connect`** на мобиле скрыт, но `data-copy` всегда копирует полную команду.

## 7. Проверка после изменений

Минимум:

1. Страница загружается, занавес уходит, в консоли только ожидаемые 404 `/api/*`.
2. Онлайн и таймер отображаются; график рисуется (реальный или демо).
3. Вкладки правил переключаются мышью и стрелками; счётчики 4/5/7/4.
4. Копирование показывает тост.
5. Меню на 390 px: открывается, фокус на первой ссылке, Escape/крестик возвращают фокус на «Меню».
6. Нет горизонтального скролла на 320/390/430/768/1280.
7. Юридические страницы: шрифты, логотип, занавес, нет 404 ассетов.

Полный чек-лист — `docs/QA.md`.
